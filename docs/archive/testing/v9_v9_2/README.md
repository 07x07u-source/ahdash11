# Archived pre-V10 visual tests

Phase H.2 moved the ten obsolete Dart sources in `source/` outside
`mobile/test/` without changing them. Their historical PNG baselines remain in
their existing `docs/visual-validation/` and `docs/screenshots/` locations.
They target V7/V8/V9/V9.2, retired Landscape/Dark compositions, and in several
cases the removed legacy Thmanyah Serif font. They are history, not V10 design
authority, and must not be restored to active discovery or regenerated.
