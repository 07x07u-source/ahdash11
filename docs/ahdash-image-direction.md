# اتجاه صور أحدعش

## المطلوب

- لقطة كروية واضحة تُفهم سريعًا دون نص مطبوع داخل الصورة.
- تكوين قوي بمركز اهتمام واحد، ومساحة سالبة تسمح بالقص 3:2 و4:3.
- إضاءة طبيعية أو تحريرية هادئة، contrast متوسط، ودفء محسوب في الظلال.
- سياق سعودي يأتي من المحتوى الحقيقي واللغة، لا من الكليشيهات البصرية.
- Illustration أصلي أو مولّد ومراجع مقبول عندما لا تتوفر صورة فوتوغرافية مملوكة.

## القص

- Master موصى به 3:2 أو 4:3، عرض 1600px أو أكثر عند الإمكان.
- يحفظ المحرر `focal_x` و`focal_y` من 0 إلى 1.
- يجب مراجعة crop عريض ومضغوط قبل النشر؛ لا يطلب النظام خمس نسخ من الأصل.
- لا يوضع وجه، كرة، كأس أو حركة حاسمة قرب حافة غير آمنة.

## الحقوق

- الحالات المقبولة: `original` أو`generated` أو`licensed` فقط.
- يُحفظ المصدر وattribution عندما يلزم، مع alt text عربي مفيد.
- يمنع استخدام Google Images أو شعارات أندية/دوريات غير مرخّصة.
- عند ظهور أشخاص يجب وجود موافقة/ترخيص صالح للاستخدام المقصود، خصوصًا القاصرين.

## Do / Don't

| افعل | لا تفعل |
|---|---|
| صورة نظيفة وهوية لونية متقاربة | Thumbnail يوتيوب أو poster دعائي |
| موضوع واحد ومشهد مقروء | نص كبير أو شعار داخل الصورة |
| grading دافئ خفيف | Sepia كامل أو فلتر واحد قاسٍ |
| مصدر موثق وalt واضح | تنزيل صورة مجهولة وإعادة رفعها |
| WebP عند ملاءمة pipeline | ضغط يدمر التفاصيل أو ملف 8MB لكل tile |

في Flutter تُحمّل الصور عبر `CachedNetworkImage` مع أبعاد cache محسوبة، version query من Media Library، وfallback محلي يحجب broken-image icon. آخر نسخة ناجحة تبقى في cache وفق سلوك المكتبة؛ لا تُخزّن إجابات سرية ضمن مسار الصور.
