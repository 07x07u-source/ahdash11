# قبل/بعد V6 — سجل المقارنة

هذا الملف يبدأ بالتشخيص ويُحدّث بعد كل checkpoint مرئي.

| الشاشة | قبل V6 | هدف V6 |
|---|---|---|
| الدخول | تقسيم متساوٍ وصندوق نموذج | افتتاح تحريري واحد، علامة واضحة، وفعل دخول مركزي في التسلسل لا في صندوق معزول |
| الرئيسية | dashboard من ثلاثة أعمدة | قصة لعب تقودها دعوة كبيرة وصورة، مع معلومات ثانوية على خط تحريري |
| الفئات | قائمة ضيقة + معاينة ضخمة فارغة | جدار صور قابل للمسح، عدّاد 6/6 واضح، ومعاينة متصلة بالاختيار |
| السؤال | إطار كبير و4 بطاقات إجابة | مسرح سؤال مقروء عن بعد، دور ونتيجة واضحان، وإجابات كصفوف/مساحات لا صناديق متكررة |
| الملف | metrics وبطاقات | غلاف لاعب وسجل سردي وتبويب بطولة كفصل واحد |
| مباراة البطولة | مستطيلان فارغان | مواجهة بصرية بين اسمين ونتيجة مركزية وخط بطولة ذهبي |
| وسائل المساعدة | مساحة ميتة وعناصر صغيرة | خمس أدوات ذات وزن بصري وتوزيع يشرح 3 لكل فريق |
| اللوحة | grid بطاقات | scoreboard موحد بخطوط رفيعة وصور فئات |
| Premium | تقسيم فارغ | قيمة وخطة وفعل واضح، بذهبي محدود |
| الإعدادات | ثلاثة أعمدة إدارية | فصول تحريرية على صفحة واحدة مع روابط صفية واضحة |

## شروط إغلاق المقارنة

- توليد الشاشات الست الأولى في Light/Dark ومراجعتها معًا.
- إعادة توليد بقية الحالات والمقاسات المطلوبة.
- فتح الصور الفعلية وعدم الاكتفاء بنجاح golden test.
- توثيق أي فرق مقصود أو حالة لم يمكن التحقق منها حيًا.
