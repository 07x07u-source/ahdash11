# Settings & Report — Final UI Review

تمت مراجعة وتحسين شاشتي `17_settings` و`18_report` مع الحفاظ على مسارات التطبيق وعقود الخدمات الحالية.

## التحسينات

- هوية أوضح للإعدادات مع حالات الحساب والضيف وPremium.
- تحكم مباشر في الصوت والاهتزاز وتقليل الحركة مع حفظ فوري للتفضيلات.
- تجميع الحساب والإشعارات والدعم والخصوصية والجلسة ضمن أقسام أسهل للمسح البصري.
- نوافذ سفلية محسّنة لتجربة اللعب والإشعارات مع شرح مختصر لكل خيار.
- نموذج بلاغ متدرج بخطوتين، إرشادات خصوصية، عداد أحرف، وحالات نجاح وخطأ وعدم يقين.
- زر إرسال ثابت وقابل للوصول عند ظهور لوحة المفاتيح وعلى الشاشات الصغيرة.
- صورتان مخصصتان بخلفية شفافة لهوية اللاعب والدعم، محسّنتان للحجم الصغير ومحفوظتان داخل أصول التطبيق.

## التحقق

- 47 حالة مراجعة بصرية: مقاسا 390×844 و360×800، تكبير نص 100% و130% و200%، حالات Standard وPremium وGuest، حالات البلاغ، لوحة المفاتيح، ونوافذ الإعدادات السفلية.
- 39 اختبار سلوك وتوافق تغطي الحفظ الفوري للتفضيلات، إرسال البلاغ، المقاسات 360–430، واتجاه RTL.
- `flutter analyze --no-pub`: لا توجد ملاحظات.
