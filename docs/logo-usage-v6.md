# استخدام شعار أحدعش V6

## المصدر الوحيد

- `mobile/assets/branding/logo-horizontal.png`
- `mobile/assets/branding/logo-symbol.png`
- `mobile/assets/branding/logo-wordmark.png`

هذه الملفات هي النسخ المحلية القانونية عالية الدقة. النسخ المطابقة في حزمة العلامة ولوحة الإدارة ليست شعارات جديدة.

## الأولوية

يقرأ التطبيق فتحات العلامة البعيدة (`branding.logo.primary`, `branding.logo.dark`, `branding.logo.mark`) ثم يعود إلى الملفات المحلية. لا يتم توليد الشعار أو تتبعه أو إعادة رسمه.

## القواعد

- الشعار الأفقي للافتتاح والدخول والشاشات التسويقية.
- الرمز للتنقل الضيق والعلامات الصغيرة.
- لا يوضع الشعار داخل بطاقة افتراضية في كل شاشة.
- على الخلفية الداكنة يستخدم الأصل البعيد المخصص إن وجد؛ وإلا يوضع الأصل القانوني على مساحة ورقية مقصودة توفر التباين، من دون تعديل ألوانه.
- يمنع التمديد، الظلال الثقيلة، التدرجات فوق الشعار، أو استعماله كزخرفة متكررة.

## نتيجة التدقيق

الأبعاد المحلية: الأفقي والكلمة 2172×724، والرمز 1254×1254، مع alpha. لا يوجد SVG قانوني معتمد داخل المستودع، ولذلك لا ينشأ SVG بديل.
