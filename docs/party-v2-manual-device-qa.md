# أحدعش | 11 — قائمة QA يدوية على جهاز Android حقيقي

سجّل لكل بند: الجهاز، Android، الدقة، Light/Dark، النتيجة، وصورة/فيديو عند الفشل. لا يُعد نجاح البناء إثباتًا لنجاح الشبكة أو Google أو FCM أو RevenueCat.

## البداية والتنقل

- [ ] أول تشغيل يعرض Onboarding الأربع، والتخطي/التالي/ابدأ يعمل.
- [ ] Home تعرض أحدعش و«جاهزين للتحدي؟» و«ابدأ لعبة» فورًا بلا dashboard أو قص رأسي.
- [ ] الحساب والإعدادات وPremium وكيف تلعب والمفضلة والألعاب السابقة تفتح المسار الصحيح.
- [ ] زر استئناف الجولة يظهر فقط عند وجود جولة ويرجع إلى حالتها الفعلية.

## الفئات

- [ ] بدء لعبة يفتح Browser الفئات وتظهر الصور/البدائل بلا وميض أو broken layout.
- [ ] البحث يعمل بالعربية والإنجليزية والتهجئات المكافئة.
- [ ] «الأحدث» يعرض المحتوى الموسمي/الجديد الصحيح.
- [ ] المفضلة تضاف وتزال وتبقى بعد إغلاق التطبيق، وتُدمج للحساب إن كان ذلك مفعّلًا.
- [ ] الاختيار العشوائي يملأ ست فئات متنوعة ولا يختار فئة غير جاهزة.
- [ ] ثلاثة اختيارات لكل فريق تظهر بملكية واضحة ويمكن تعديلها.
- [ ] تفاصيل الفئة وتجربة السؤال تفتحان، والتجربة لا تخصم سؤالًا ولا تسجل نقاطًا/تاريخًا.
- [ ] فئات Premium/free rotation تتبع الاستحقاق والإعداد البعيد الصحيح بعد تطبيق migration.

## الفرق والمساعدات

- [ ] اسما الفريقين يقبلان العربية ويظهران دون قص، والألوان تبقى واضحة في Light/Dark.
- [ ] «قسمنا» يقبل أسماء اللاعبين، يقسمهم بتوازن، ويسمح بالتجاوز دون أثر.
- [ ] كل فريق يختار ثلاث أدوات فقط من الخمس، والوصف والتوقيت واضحان.
- [ ] الأداة المستعملة لا تستخدم مرتين، والأداة غير المؤهلة لا تنفذ.
- [ ] Ready تعرض الفريقين والفئات والمساعدات والمؤقت، وزر بدء الجولة واضح.

## الجولة

- [ ] Board تعرض 6×6 وقيم 100/200/300 والدور والنتيجة، والسؤال المستخدم لا يفتح ثانية.
- [ ] سؤال النص مقروء عن بعد ولا يقع داخل Card عملاقة.
- [ ] الاختيار المتعدد وصح/خطأ يقبلان التحديد الصحيح.
- [ ] سؤال الصورة يحمل الوسائط أو يعرض fallback مفهومًا عند فشلها.
- [ ] المؤقت، reveal، الإجابة، منح النقاط، عدم المنح، وتبديل الدور يعمل كل منها مرة واحدة.
- [ ] عداد النقاط يطابق الحالة المحفوظة بعد الرجوع/الإغلاق والاستئناف.
- [ ] النتيجة تعلن الفائز/التعادل، وإعادة الجولة/العودة إلى Home تعمل دون جلسة معلقة.

## الحركة والصوت والوصول

- [ ] press/page/reveal/score/shuffle/confetti سلسة ولا تمنع النقر المزدوج الآمن.
- [ ] Reduced Motion يوقف الخلفية والـconfetti والارتداد والانتقالات الكبيرة.
- [ ] إيقاف الصوت يمنع المؤثرات، وإيقاف Haptics يمنع الاهتزاز.
- [ ] الصوت وHaptics يعملان عند تمكينهما على جهاز يدعمهما.
- [ ] العربية RTL صحيحة في الحقول، القوائم، الأرقام المختلطة، والحوارات.
- [ ] جرّب Light/Dark وتغييرهما أثناء التنقل والجولة.
- [ ] افحص landscape على هاتف صغير وكبير/جهاز لوحي أو casting؛ لا overflow أو عناصر مقصوصة.

## الشبكة والحساب والتجارة

- [ ] Guest start يعمل حسب سياسة المنتج ولا يجعل الحساب حاجزًا غير مقصود.
- [ ] إنشاء الحساب والدخول والبقاء في الجلسة يعملان على Supabase الحقيقي.
- [ ] Google Sign-In الأصلي يكتمل على نسخة Release ذات SHA الصحيحة.
- [ ] Offline قبل تحميل الفئات وأثناء الجولة يعرض حالة قابلة للاسترداد ويحفظ الجولة المحلية.
- [ ] Loading/Error/Retry لا يكرر إنشاء جلسة أو خصم استحقاق.
- [ ] Premium يعرض أسعار Google Play الحقيقية والشراء/الاستعادة عبر RevenueCat.
- [ ] Free limits وfree rotation تتبع إعداد Admin ولا تتجاوز الاستحقاق.
- [ ] FCM يسجل Device Token وتصل إشعارات foreground/background/tap بعد تفعيل بيئة Firebase الفعلية.

## الجودة والبلاغات

- [ ] FAQ تغطي اختيار الفئات، المساعدات، النقاط، Premium، التجربة المجانية، الأعطال والبلاغ.
- [ ] بلاغ السؤال يرسل كل سبب: خطأ، قديم، غير واضح، مكرر، وسائط معطلة، أخرى.
- [ ] البلاغ المكرر/فشل الشبكة يعرض نتيجة واضحة دون تعليق الواجهة.
- [ ] Admin يعرض metadata وصحة الجاهزية والوسائط والحقوق بعد تطبيق migration يدويًا.
- [ ] راقب زمن بدء الجولة والتنقل واستهلاك الذاكرة في جولة كاملة من 36 سؤالًا.
- [ ] لا تظهر XP/Ranking/Social/Coins/Wallet/1v1/2v2/Rooms في المسار العام Party V2.
