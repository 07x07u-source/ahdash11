# دليل لعبة أحدعش 11 — الهاتف والكمبيوتر

> آخر تحديث: 12 سبتمبر 2026  
> الإصدار الحالي للتطبيق: `0.1.0+1`  
> معرّف الحزمة الموحد: `com.ahdash.eleven`

## 1. تعريف المنتج

أحدعش 11 لعبة مسابقات كرة قدم عربية تركز على المعرفة، اللعب الاجتماعي، التحديات والبطولات. يتكوّن المنتج من ثلاث واجهات مترابطة:

1. تطبيق الهاتف المبني بـFlutter لأجهزة Android وiPhone.
2. موقع الكمبيوتر المبني بـNext.js للعب وإدارة الحساب والبطولات.
3. لوحة تحكم للطاقم لإدارة المحتوى والمستخدمين والعمليات.

الخلفية المشتركة مبنية على Supabase/PostgreSQL وتحتوي على الحسابات، الأسئلة، النتائج، العلاقات الاجتماعية، البطولات، الاقتصاد، الاشتراكات، الإشعارات والبلاغات.

## 2. سياسة الأجهزة

### الهاتف

- الهاتف لا يعرض نسخة موقع اللعب.
- عند فتح أي رابط عام للموقع من هاتف، تظهر صفحة تنزيل التطبيق.
- الصفحة تعرض خيار App Store وخيار Google Play.
- لا توضع روابط وهمية: إذا لم تُضبط روابط النشر الرسمية يظهر الزران بحالة «قريباً».
- اكتشاف الهاتف يتم من الخادم، مع استجابة احتياطية للشاشات الضيقة.

### الكمبيوتر

- الموقع الكامل متاح على الكمبيوتر.
- يمكن استعراض الأنماط والبطولات والصفحات القانونية دون حساب.
- اللعب وإنشاء بطولة والانضمام إليها ومركز اللاعب تتطلب حساباً مسجلاً.
- الحماية منفذة على الخادم، وليست مجرد إخفاء للأزرار.

### روابط المتاجر المطلوبة

تُضبط القيم التالية في بيئة الموقع بعد إنشاء صفحات النشر الرسمية:

```env
NEXT_PUBLIC_APP_STORE_URL=https://apps.apple.com/...
NEXT_PUBLIC_GOOGLE_PLAY_URL=https://play.google.com/store/apps/details?id=com.ahdash.eleven
```

لم تُضف روابط تطبيق غير منشور أو أرقام App Store مخمّنة.

## 7. رحلة المستخدم على الكمبيوتر

### 7.1 الصفحات العامة

| المسار | الوظيفة |
|---|---|
| `/` | الصفحة الرئيسية |
| `/games` | اختيار نوع اللعبة وطريقة الجولة |
| `/championships` | استعراض البطولات |
| `/support` | الدعم والأسئلة المتكررة |
| `/legal` | المركز القانوني |

### 7.2 الحساب

| المسار | الوظيفة |
|---|---|
| `/account/login` | تسجيل الدخول |
| `/account/register` | إنشاء حساب |
| `/account/recover` | طلب استعادة كلمة المرور |
| `/account/reset` | تعيين كلمة مرور جديدة |
| `/auth/callback` | تأكيد البريد وتبادل جلسة Supabase |
| `/account` | مركز اللاعب |

بعد تسجيل الدخول يعود المستخدم تلقائياً إلى الصفحة التي حاول فتحها قبل الدخول.

### 7.3 المسارات المحمية

- `/play`: اللعب الفعلي.
- `/championships/create`: إنشاء بطولة.
- `/championships/join`: الانضمام إلى بطولة.
- `/account` وكل الصفحات الفرعية له.

إذا لم توجد جلسة صحيحة يُعاد المستخدم إلى تسجيل الدخول مع حفظ وجهته.

### 7.4 مركز اللاعب على الكمبيوتر

يتضمن:

- الملف الشخصي وتعديل الاسم واسم المستخدم.
- الألعاب المحفوظة.
- التصنيف.
- الأصدقاء وطلبات الإضافة.
- الفرق وتحدي الفريق.
- بطولاتي والإنشاء والانضمام.
- الإشعارات.
- الاهتمامات الكروية والنادي المفضل.
- Premium.
- المتجر والقسائم.
- اللاعبون المحظورون.
- إعدادات اللعب.
- إرسال بلاغ مشكلة.

### 7.5 البطولات على الكمبيوتر

إنشاء البطولة يرسل البيانات إلى دالة الخادم `create_tournament` ويخزن:

- اسم البطولة.
- النظام: خروج مغلوب، دوري نقاط أو مجموعات.
- عدد المشاركين.
- حجم الفريق.
- فئات الأسئلة.
- التاريخ والوقت.
- المؤقت والمساعدات وكسر التعادل.
- رمز الانضمام.

الانضمام يستخدم `register_tournament_team` ويرسل طلباً إلى المنظم بدلاً من إضافة الفريق دون مراجعة.

لوحة التحكم مخصصة للطاقم وليست للاعب العادي. أهم أقسامها:

- لوحة العمليات والمؤشرات.

- الأقسام والأسئلة والخيارات.
- الاستيراد من CSV وExcel.
- الوسائط والهوية.
- البطولات والمباريات.
- التواصل الاجتماعي والإشراف.
- الإشعارات والحملات.
- Premium والقسائم والمتجر.
- بلاغات الأسئلة ومشكلات المستخدمين.
- سجل التدقيق وصحة النظام والإعدادات.

الوصول الإداري يخضع إلى دور المستخدم وسياسات RLS، وليس إلى إخفاء الواجهة فقط.

## 9. الحسابات والصلاحيات

### اللاعب المسجل

- ملف شخصي مرتبط بمعرّف Supabase Auth.
- نتائج ومستوى وخبرة وتصنيف.
- أصدقاء وفرق وبطولات وإشعارات.
- تفضيلات كروية وخصوصية.
- اشتراك ومخزون عند التفعيل.

### الأدوار الإدارية

- مستخدم عادي.
- مشرف محتوى/مجتمع.
- مدير بحسب الصلاحيات المعرفة في قاعدة البيانات.

### قواعد الحماية

- JWT وجلسات Supabase للحسابات.
- Row Level Security لكل البيانات الحساسة.
- دوال RPC للعمليات التي تحتاج تحققاً وخطوات ذرية.
- تحديد معدلات لبعض الإجراءات مثل إنشاء البطولات والبلاغات.
- لا يُرسل مفتاح `service-role` إلى الهاتف أو المتصفح.

## 10. البيانات والخلفية

- `profiles`: ملفات اللاعبين.

- `subscriptions`, `store_items`, `user_inventory`: الاشتراك والمتجر.

## 15. النشر

### Android

- المعرّف: `com.ahdash.eleven`.
- يلزم Play App Signing ومفتاح رفع إنتاجي.
- يلزم `google-services.json` الصحيح.
- يلزم ضبط App ID إنتاجي لـAdMob.
- الناتج النهائي المفضل للنشر: AAB.

### iOS

- Bundle ID: `com.ahdash.eleven`.
- الحد الأدنى الحالي: iOS 13.
- يلزم Apple Developer وApp Store Connect.
- يلزم ملف provisioning وشهادة توزيع.
- يتوفر مسار بناء ورفع عبر Codemagic/TestFlight.

### موقع الكمبيوتر

- يتطلب متغيرات Supabase العامة الآمنة.
- يحتاج عنوان إنتاج موثوق في `NEXT_PUBLIC_APP_URL`.
- يحتاج روابط App Store وGoogle Play بعد النشر.
- لا يتطلب نشر جديد لمجرد تعديل الملفات محلياً.
