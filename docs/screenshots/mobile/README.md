# معرض شاشات أحدعش | 11

هذا هو الفهرس المركزي للقطات التطبيق الفعلية المولدة من Flutter Widget Tests من دون تشغيل محاكي. البيانات الظاهرة في الشاشات المتصلة بالخادم بيانات معاينة ثابتة وآمنة، وليست اتصالًا بمشروع Supabase الحقيقي.

- إجمالي الصور: **404 صورة PNG**.
- الأوضاع: Light وDark.
- المقاسات: خمسة مقاسات هاتفية أفقية للشاشات الأساسية وParty والبطولات، مع لقطات مرجعية 1280×720 للصفحات الإضافية. تحدي الفريق 1280×760 ليستوعب المحتوى كاملًا.
- المجلدات: [الصفحات الإضافية](pages/)، [الشاشات الأساسية](../../visual-validation/goldens/)، [Party](../../visual-validation/party/)، [البطولات](../../../mobile/test/visual/goldens/tournament/).
