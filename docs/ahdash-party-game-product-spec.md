# مواصفة لعبة الجلسة — أحدعش | 11

تاريخ القرار: 30 أغسطس 2026.

## وعد المنتج

لعبة أسئلة كرة قدم عربية تبدأ خلال ثوانٍ، يلعبها فريقان حول جهاز واحد، ويعمل الجهاز كمضيف للجولة. لا يحتاج اللاعبون إلى حسابات منفصلة، ولا إلى عملات أو شراء كل لعبة.

## المسار الأساسي

`الرئيسية ← الأقسام ← الفريقان ← المساعدات ← جاهزين ← لوحة 6×6 ← السؤال ← كشف الإجابة ← احتساب النقطة ← اللوحة ← النتيجة`

- 6 أقسام بالضبط؛ يملأ الفريق الأول أول ثلاث خانات، ثم يملأ الفريق الثاني الخانات الثلاث التالية. تظهر الملكية بالألوان أثناء الاختيار.
- 6 أسئلة لكل قسم: سهلان، متوسطان، صعبان.
- 36 سؤالًا فريدًا بقيم 100، 100، 200، 200، 300، 300.
- الفريق صاحب الدور يختار القسم والقيمة. بعد احتساب السؤال ينتقل الدور.
- الحفظ محلي بعد كل فعل مهم، وتظهر متابعة اللعبة في الرئيسية و«ألعابي».

## قرارات تجربة المستخدم

- الرئيسية تعرض الشعار وزر «ابدأ لعبة» بوصفه الإجراء المسيطر.
- الإجراءات الثانوية: ألعابي، الأقسام، طريقة اللعب، والحساب/الإعدادات بحجم صغير.
- اللعب المتصل محفوظ كمدخل ثانوي ولا يظهر بوصفه ست ألعاب متنافسة في الرئيسية.
- لا شريط تنقل جانبي دائم داخل المسار الأساسي، ولا XP أو ترتيب أو ترويج أثناء السؤال.
- اللوحة الأساسية بلا تمرير رأسي في الوضع الأفقي، مع مسار وصول بديل عند تكبير النص.
- الواجهة عربية RTL، والأسماء الإنجليزية تُعرض دون كسر ترتيب الأرقام أو الروابط.

## الهوية والأصالة

المنتج يستفيد من مبادئ عامة مثبتة: إعداد قصير، اختيار مشترك، لوحة قيم، مضيف محلي ومساعدات محدودة. الأسماء، القواعد، الألوان، الرسوم، النصوص، بنية المكونات، والتسلسل البصري خاصة بأحدعش. لا تُستخدم علامة أو أصول أو trade dress لمنتج مرجعي.

## الحساب والضيف

يدخل المستخدم ضيفًا عبر Supabase Anonymous Auth الموجود، فيستطيع الوصول إلى بنك party غير التنافسي. الحساب مطلوب للمزامنة والمفضلة البعيدة وPremium والاجتماعي، وليس شرطًا لوجود أسماء أعضاء الجلسة.

## خارج نطاق الإصدار الحالي

الصوت والفيديو وhotspots والترتيب التفاعلي ليست معلنة كصيغ منفذة حتى تكتمل مكتبة وسائط مرخصة ومشغلات واختبارات وصول خاصة بها. لا يذكر التقرير النهائي إلا الصيغ التي نجحت فعليًا.
