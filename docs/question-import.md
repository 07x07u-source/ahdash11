# استيراد الأسئلة

## القالب البسيط

الأعمدة المقبولة بالعربية أو aliases الإنجليزية:

| مطلوب | العمود               | الوصف                                |
| ----- | -------------------- | ------------------------------------ |
| نعم   | السؤال               | نص غير فارغ                          |
| نعم   | الخيار الأول..الرابع | أربعة خيارات مختلفة                  |
| نعم   | الإجابة الصحيحة      | تطابق أحد الخيارات بعد normalization |
| لا    | الصورة - اختياري     | رابط Storage أو اسم ملف مصرح به      |

يحفظ النظام النص الأصلي للمعاينة، ثم ينشئ normalized form للمقارنة فقط؛ لا يغيّر كتابة السؤال المنشور خفية.

## خط المعالجة

1. **Parse:** قراءة XLSX/CSV مع تحديد encoding والعناوين.
2. **Structural validation:** الأعمدة، السؤال، أربعة خيارات، الإجابة ضمن الخيارات، طول الحقول.
3. **Normalization:** إزالة المسافات الزائدة والتطويل، توحيد أشكال الألف/الياء والأرقام لأغراض البحث.
4. **Exact duplicate:** بصمة normalized question + options.
5. **Similarity:** token/Jaccard أو trigram مقابل batch وقاعدة البيانات، مع threshold قابل للتعديل. النتيجة إنذار للمراجع وليست حذفًا تلقائيًا.
6. **Classification:** قواعد كلمات مفتاحية واسم الملف وmetadata إلى category/subcategory/tags/entities/difficulty.
7. **Confidence:** التصنيف دون العتبة يضبط `needs_review=true`.
8. **Preview:** عرض كل صف وأخطائه وتحذيراته والتعديلات المقترحة.
9. **Commit:** Function/RPC تعيد التحقق وتكتب الصفوف المقبولة ذريًا مع audit metadata.

## حالات الصف

`pending`, `valid`, `invalid`, `needs_review`, `approved`, `imported`, `skipped`. لا تنشر الصفوف ذات الخطأ أو منخفضة الثقة تلقائيًا. يمكن للمشرف تعديل التصنيف أو الإجابة قبل الاعتماد الجماعي.

## الصور

لا يجلب المستورد صورًا من الإنترنت. يرفع المشرف الملفات المصرح بها إلى bucket خاص بالإدارة، ثم تحفظ قاعدة البيانات مسار Storage. تحقق الخادم من MIME والحجم والامتداد، ويولد URL موقّعًا أو public بحسب سياسة المنتج.

## إضافة LLM مستقبلًا

واجهة `ClassificationService` تعيد نتيجة typed تحتوي category candidates وtags/entities/difficulty/confidence/reasons. التنفيذ القاعدي هو الافتراضي. يمكن إضافة provider خارجي كمرحلة اختيارية؛ لا ينشر مباشرة ولا ترسل إليه بيانات مستخدمين.
