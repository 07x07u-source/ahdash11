# أحدعش | 11 — اتجاه الصور V7

## الفكرة

الصورة تمنح اللعبة طاقة كرة القدم، بينما الورق الدافئ والحبر يمنحانها صوتها التحريري السعودي. لا تُستخدم الصورة كخلفية عشوائية أو كتعويض عن hierarchy ضعيفة.

## قواعد الاختيار

- موضوع كروي واضح من النظرة الأولى: ملعب، كرة، قميص، مدرج، لحظة منافسة، أو شخصية مرتبطة مباشرة بالفئة.
- قصّ نظيف ونقطة تركيز واحدة قابلة للضبط عبر focal point.
- تدرج لوني متسق: ظلال حبرية دافئة، highlights محدودة، وأخضر العلامة لا يُصبغ فوق الصورة كلها.
- لا watermark، لا نص مطبوع داخل الصورة، لا شعارات قنوات أو بطولات غير مصرح بها.
- لا صور stock عامة من نوع “رجل أمام لابتوب” أو “كرة فوق عشب” مكررة لكل فئة.
- لا علم أو نخلة أو سيف أو سدو في كل شاشة. النبرة السعودية تأتي من اللغة والإيقاع والمساحة والهوية، لا من كليشيه بصري متكرر.
- لكل أصل سجل مصدر ومالك وحقوق واستخدام وانتهاء صلاحية عند الحاجة.

## التكوين حسب السطح

| السطح | النسبة/القص | القاعدة |
|---|---|---|
| Login | full-bleed landscape | مساحة سالبة كافية للنص، subject بعيد عن حقول الدخول |
| Home feature | 16:9 أو 3:2 | لقطة واحدة مهيمنة، overlay قصير، لا card داخل card |
| Category cover | 4:3 أو 3:4 حسب التكوين | هوية فريدة لكل فئة ونقطة تركيز محفوظة |
| Board header | شريط عريض منخفض | thumbnail مقروءة من بعيد ولا تنافس أرقام اللوحة |
| Question image | نسبة الأصل مع contain/cover مقصود | لا crop يخفي المعلومة اللازمة للإجابة |
| Profile | 16:9 cover + avatar | الهوية الشخصية لا giant poster ثابت |
| Tournament | wide editorial cover | صورة تنافسية واحدة، والذهب للحظة البطل فقط |

## التحميل والـfallback

- الصور البعيدة تمر عبر `AhdashImage`/`cached_network_image` فقط.
- placeholder يحتفظ بنسبة المساحة ويستخدم لون surface ونمط 11 خفيفًا؛ لا spinner متكرر.
- fallback محلي خاص بالسياق، وليس broken-image icon.
- `memCacheWidth` و`memCacheHeight` يطابقان حجم العرض الفعلي وكثافة الشاشة.
- prefetch يقتصر على أغلفة الفئات المختارة ووسائط السؤال التالي عند منطق اللعبة الآمن.
- cache busting يعتمد media version/URL المقدم من المكتبة، لا query عشوائي في الواجهة.

## تدقيق الأصول الحالية

- الأصول القانونية للشعار تبقى كما هي.
- `home-hero.png` و`login_landscape_v2.webp` و`profile_background.webp` قابلة لإعادة القص، لكن لا يجب تكرار المشهد التكتيكي نفسه عبر الفئات.
- صورة العين/الملعب المستخدمة حاليًا في معظم أغلفة الفئات تُعامل كـfallback فقط، لا كغلاف منشور متكرر.
- أصول coin/store القديمة لا تدخل UX العام في V7.
- لا يوجد `.riv` ولا ملفات SFX محلية مرخصة؛ لا تُختلق أصول ثنائية أو صوتية.

## بوابة النشر

الفئة المنشورة يجب أن تملك:

1. `cover_media_id` صالحًا.
2. `image_url` عامًا صالحًا من Media Library.
3. حالة حقوق معتمدة.
4. focal point بين 0 و1.
5. عدم تكرار الأصل نفسه كغلاف لفئات متعددة إلا إذا كان fallback غير منشور.

الهدف قبل release: `published_without_valid_cover = 0`.
