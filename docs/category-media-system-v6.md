# نظام وسائط الفئات V6

## نتيجة التدقيق

لا تحتاج V6 إلى migration جديدة. migration الحالية `20260831000300_editorial_brand_category_media_v5.sql` تحقق المتطلبات التالية:

- `cover_media_id` و`image_url` للفئة.
- نقطة قص أفقية وعمودية بين 0 و1.
- تحقق من نوع الصورة وحالة الأصل وحقوقه.
- منع نشر فئة فعالة بلا غلاف صالح.
- منع أرشفة أصل مستخدم في فئة منشورة.
- view باسم `category_media_audit` يعيد `media_health`.
- دالة إدارية مدققة لتحديث الغلاف والوصف ونقطة القص مع audit log.

لوحة الإدارة الحالية تدعم اختيار الأصل من المكتبة، 3:2 و4:3، نقطة القص، الحقوق، وحالة الوسائط. المطلوب في V6 هو تحسين تركيب العرض والتحذير، لا تغيير المخطط.

## حالات الصحة

- `ready`: صالح للنشر.
- `needs_media`: الغلاف غير مكتمل.
- `missing_asset`: المرجع غير موجود.
- `archived_asset`: الأصل مؤرشف.
- `invalid_media`: النوع غير مسموح.
- `rights_issue`: الحقوق غير معتمدة.
- `not_published`: لا يطبّق حاجز النشر بعد.

## سياسة النشر

أي فئة `is_active = true` و`editorial_status = published` يجب أن تكون `ready`. لا يغيّر تطبيق الهاتف هذه السياسة، بل يقرأ الصورة ونقطة القص ويعرض بديلًا ورقيًا آمنًا فقط للحالات غير المنشورة/الاختبارية.

## قرار قاعدة البيانات

لن يتم تشغيل `db push`، ولن تعدّل migration مطبقة، ولن تضاف migration لمجرد إعادة تصميم العرض.
