نتيجة الفحص الأمني

تم فحص ملفات التطبيق، لوحة التحكم، Supabase Functions، إعدادات RLS، الأسرار المتتبعة، وروابط المصادقة. لم يظهر مفتاح service role متتبعًا في Git، ومفتاح الهاتف الموجود هو anon/public key فقط.

  • ✓ لا توجد مفاتيح خاصة أو ملفات p8/pem متتبعة
  • ✓ Edge Functions الحساسة محمية بـ JWT أو حارس سرّي داخلي
  • ✓ اختبارات لوحة التحكم (86 اختبارًا) وملف Codemagic بصيغة YAML سليمة
  • عالي تبعية sharp في لوحة التحكم لديها تنبيه npm audit عالي الخطورة؛ يلزم تحديثها إلى الإصدار الآمن بعد اختبار التوافق
  • متوسط بعض استجابات Supabase قد تعيد رسالة الخطأ الخام؛ يُفضّل إخفاء تفاصيل قاعدة البيانات في الإنتاج
  • تحصين قيمة ALLOWED_ORIGINS الافتراضية هي *؛ اضبط النطاقات الفعلية في بيئة الإنتاج
  • تحصين تأكيد البريد معطّل في إعدادات Supabase؛ فعّله إذا كان التسجيل العام يحتاج منع الحسابات الوهمية
  • تنبيه محلي متغير service role موجود فارغًا في admin/.env.local المحلي؛ يُفضّل حذفه لتقليل خطر تعبئته بالخطأ
