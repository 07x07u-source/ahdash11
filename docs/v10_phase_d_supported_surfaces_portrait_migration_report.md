# V10 Phase D — Supported Surfaces Portrait Migration

## النتيجة

نُقلت الشاشات 17 و18 و28 و29 و33–37 إلى مسار V10 العمودي الفعّال، مع إبقاء المصدر الوظيفي الحقيقي لكل شاشة وعدم إضافة بيانات عرض تجريبية إلى الإنتاج.

## قرارات المنتج

- How to Play يشرح عقد Party الحقيقي: 6 فئات، فريقان، 3 فئات لكل فريق، 36 سؤالًا، اختيار المساعدات، كشف المضيف للإجابة ومنح النقاط يدويًا. المساعدات الخمس مأخوذة من `PartyHelperId`، و`call_friend` مؤقت داخلي فقط.
- Saved Party Games يعتمد مخزن جلسات Party الحالي وresolver الاستعادة نفسه لحالات Setup وReady وBoard وQuestion وReveal وResult؛ لا توجد بطاقات إنتاج وهمية.
- Match Setup يفعّل Classic وTrue/False وSpeed فقط. الأنماط غير المدعومة موسومة «قريبًا»، وOnline يبقى معطّلًا ومحميًا بالتحويل الآمن.
- Solo: **LIMITED**. المحرك الحقيقي يعمل من البداية للنهاية، لكن الواجهة تعرض فقط الفئات والصعوبة وعدد الأسئلة المدعوم حاليًا؛ لا أعداد توفر أو XP أو تقدم مصطنع.
- Team Challenge: **IMPLEMENTED**. المسار يعتمد controller/repository/RPC الفعلية، ويتوقف بأمان عند غياب الخدمة.
- Ranking يعرض النتائج الفعلية فقط، من دون fallback للوحة تجريبية ومن دون مرشحات شكلية غير مدعومة.
- Friends/Blocked/Team Detail تعتمد خدمات Social الحقيقية. لا presence أو last-seen. تحدي الصديق ظاهر لأن Team Challenge فعّال. فك الحظر محمي من النقر المزدوج ولا يدّعي النجاح عند فشل الخادم.
- Team Detail يعرض الاسم والوصف والأعضاء الحقيقيين والدور والدعوة المدعومة فقط؛ لا مستويات أو نسب فوز أو نتائج مصطنعة.

## التحقق

- مصفوفة RTL: 360×800، 390×844، 393×852، 412×915، 430×932 مع text scale 1.0 و1.2 و1.3.
- Keyboard: بحث الأصدقاء عند 360×800 و390×844 مع inset مقداره 300.
- Goldens: 20/20 للحالات المطلوبة، وتمت مراجعة الصور الخام يدويًا.
- اختبارات Phase D المركزة: 21/21، إضافة إلى مجموعة انحدار موجهة 201/201.
- Online لم يُفعّل، ولم تُنفذ أي عملية Backend أو Release.
