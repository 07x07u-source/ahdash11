# لوحة إدارة أحدعش | 11

تطبيق Next.js مستقل لإدارة منصة أحدعش، عربي أولًا وRTL. يستخدم Supabase Auth والجلسة الحالية وRLS؛ لا يحتاج ولا يقبل `service_role` داخل التطبيق.

## التشغيل

```bash
npm install
copy .env.example .env.local
npm run dev
```

في بيئة التطوير فقط، وعند غياب مفاتيح Supabase، تعمل اللوحة بوضع محلي واضح ومعلّم. في الإنتاج لا يوجد تجاوز للمصادقة، وأي بيئة ناقصة تعيد المستخدم إلى تسجيل الدخول.

المتغيرات المطلوبة:

```text
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
```

يجب أن يحمل المستخدم في `profiles.role` أحد الأدوار: `moderator` أو `admin` أو `super_admin`. النشر المباشر، الحملات، والإعدادات تتطلب `admin` على الأقل. الواجهة ليست مصدر الصلاحية؛ المسارات الخادمية وRLS يعيدان التحقق.

## استيراد الأسئلة

ارفع CSV أو XLSX (بحد 10MB و5,000 صف) بهذه الأعمدة:

```text
السؤال
الخيار الأول
الخيار الثاني
الخيار الثالث
الخيار الرابع
الإجابة الصحيحة
الصورة - اختياري
```

المسار `POST /api/import/parse` يقرأ الملف على الخادم، يتحقق من الصفوف، يطبّع العربية، يكشف التكرار والتشابه، ويطبق مصنّف قواعد مستقل. عند اتصال Supabase يحفظ `import_batches` و`import_rows` مع البيانات الخام والمطبّعة ونتيجة التصنيف.

بعد المراجعة يستقبل `POST /api/import/commit` قرارات الصفوف، ثم يستدعي RPC الآمنة:

```text
commit_import_batch(p_batch_id uuid, p_publish boolean)
```

الصفوف غير الواضحة تحمل `needs_review = true` ولا تُنشر تلقائيًا. الخدمة في `src/lib/import` مستقلة ويمكن توسيعها بموفر LLM اختياري لاحقًا دون تغيير تدفق الرفع.
